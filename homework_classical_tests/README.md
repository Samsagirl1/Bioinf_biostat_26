# Проверка гипотез. Классические статистические тесты

## Как выполнить и сдать

1. Откройте папку задания в Positron (`File → Open Folder`). Файл `homework_classical_tests.qmd` и папка `data` должны находиться в корне открытого проекта. Данные находятся в файле `data/nhanes.csv`.
2. Заполните `homework_classical_tests.qmd` кодом и текстовыми ответами, сохраняя структуру задания. Требования к содержанию и оформлению отчёта приведены в самом задании.
3. Используйте относительные пути от корня проекта, например `data/nhanes.csv`. Путей вида `C:/Users/…` или `/Users/…` в работе быть не должно.
4. Отрендерите заполненный файл в html кнопкой Preview в Positron или командой `quarto render homework_classical_tests.qmd`.
5. Перед сдачей убедитесь, что qmd выполняется целиком без ошибок и без объектов, созданных вручную вне отчёта. html должен соответствовать последней версии сдаваемого qmd и содержать все результаты и текстовые ответы.
6. Создайте папку `homework_classical_tests` в своём приватном репозитории GitHub и загрузите в неё qmd, html и папку `data`. Сохраните исходную структуру папки. Рекомендуем использовать уже созданный репозиторий с домашними заданиями курса.
7. Пригласите в репозиторий **GitHub-аккаунт проверки**: [bicheck2013](https://github.com/bicheck2013), если этого ещё не сделали.
8. Чтобы сдать задание, **приложите ссылку на папку `homework_classical_tests` в вашем репозитории GitHub**. По ссылке должны быть доступны оба файла отчёта и данные.
